# Cart Arena

Solo cart-battle arena in the browser. Original IP. The match shape is the public one everyone already knows — drive, grab a pickup, knock people out, three minutes — built as its own world, not a reskin.

This repository is the design home for that build. The playable match is Gutter Prix.

## Status

| | |
|---|---|
| IP | Locked. **Gutter Prix**, the Bench League. |
| Playable | Solo match: drive, tins, three weapons, seven bots, three minutes. |
| Online | Out of scope until a solo match is fun. |
| Accounts | None. A best score stays on the device. |

## v1 in one paragraph

You and seven bots on one arena for three minutes. One weapon at a time. Knockouts score. Falling off with no one to blame does not. When the clock ends, a board ranks the carts and your best knockout count is kept on this device.
